SECURITY

Listener PIN sign-inRequired

Listener sign-in and authenticated device identity are enforced by Render. Change the listener PIN in the Render service configuration; this page never displays the PIN.

HOTSPOT RECOVERY

Setup hotspotWaiting for device
Manual hotspot control

Use the switch to start or stop the setup hotspot. Turning it off is blocked unless station Wi-Fi is connected; current setup Wi-Fi clients will disconnect. Automatic recovery can start the hotspot again after Wi-Fi failures. Change its password locally at http://192.168.4.1/.

FACTORY RESET

Remote factory reset is not exposed. Use the local setup/recovery flow; ordinary debugging never clears NVS or Wi-Fi credentials.

LED SETTINGS

Status light across tabs

Blue blinking means Wi-Fi scanning; green means connected and ready. The current board firmware does not expose a configured LED pin or control API, so the switch remains unavailable until its LED hardware is identified.
